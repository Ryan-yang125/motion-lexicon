## 建议 / Recommendation

| 候选 / Candidate | 适合场景 / Fit | 区别 / Difference |
| --- | --- | --- |
| `slide-in` / 侧向切入 | 任务卡从项目详情的侧边或项目标题下方出现 | 最有“切入”方向感，落点稳定、有分量。 |
| `reveal` / 裁切揭示 | 卡片像从项目内容区被展开 | 更克制，适合卡片本来就占有固定槽位。 |
| `scale-in` / 轻微聚焦 | 卡片位于用户视线中心、需要被快速注意到 | 注意力更集中，但空间来源较弱。 |

**推荐 / Pick:** `slide-in` / 侧向切入

- 触发：项目内容加载完成后，任务卡进入预留位置。
- 节奏：`translateX(20px) → 0`，配合 `opacity: 0 → 1`，230ms，`cubic-bezier(.23, 1, .32, 1)`；不加回弹、停顿或二段缩放，所以收尾会很干净。
- 细节：终点位置从第一帧就留好空间，避免页面被挤动；若卡片在右侧栏就从右切入，若在正文首屏就从下方轻推入。
- 无障碍：`prefers-reduced-motion` 下直接到终态或用 120ms 淡入；如果卡片包含首要操作，键盘焦点仍按原有阅读顺序进入，不自动抢焦点。
