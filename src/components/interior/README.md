# Interior components

These interaction components are adapted from [ddoemonn/interior](https://github.com/ddoemonn/interior) at commit `3fd448863aac098c474a072bbc1630712504dd0d`.

They retain Interior's headless behavior and Motion feedback while using Motion Lexicon's product tokens. React 18 compatibility changes are limited to ref typing, the ES2022 array target, and project-specific composition props. See the repository `NOTICE` file for the MIT license text and attribution.
